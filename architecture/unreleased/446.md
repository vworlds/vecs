- [vecs-client] Changed: BREAKING CHANGE: `ClientWorld.connectDgram` is now an instance method, `world.connectDgram(options): Promise<void>`. Migrate `await ClientWorld.connectDgram({ ...worldOptions, ...conn })` to `const world = new ClientWorld(worldOptions)`, install modules, then `await world.connectDgram(conn)`. `DgramConnectOptions` holds only connection fields plus `signal`. On failure or abort it closes the socket and leaves the world undisposed for the caller to retry or dispose; it rejects while the world is connected or connecting (#446).
- [vecs-client] Added: `world.connectDgram` accepts an `AbortSignal` that cancels a connection in progress (#446).
- [vecs-client] Added: Export `createDgramSocket`, a `VecsSocket`-typed dgram socket factory, with `DgramSocket` and `DgramSocketOptions` (#446).
- [vecs-client] Docs: Document when to reuse a `ClientWorld` across a switch (`close` + `connectDgram`) and when to dispose it (#446).
