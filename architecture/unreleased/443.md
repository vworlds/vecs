- [vecs] Added: Watch a component without requiring it with `update({ watch: C, optional: true }, cb)` on queries and systems, so one system can watch several optional components; `onEnter: true` also fires when `C` arrives on a member and `onRemove: true` fires with the removed instance when it leaves, without an exit (#443).
- [vecs] Changed: BREAKING CHANGE: the options form of `update` requires `optional`, so every watch states whether it requires the component. Migrate by adding `optional: false` to each `update({ watch, … })` literal, which keeps today's meaning; omitting it is a type error and throws at runtime. The `update(C, cb)` shorthand is unchanged (#443).
