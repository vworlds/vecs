- [vecs] Changed: BREAKING CHANGE: `update` only watches; `with(...)` alone builds membership. `update({ watch: C }, cb)` no longer adds `C` to the predicate, the `update(C, cb)` shorthand is removed, and building a query or system that registers an `update` without any `with` terms throws. Migrate with `node <vecs checkout>/scripts/codemods/update-explicit-with.mjs <your source directories>`, then run your formatter: the script rewrites the shorthand into the options form and adds each watched component to the call's `with(...)`, which keeps today's meaning, and it prints every site it cannot rewrite and exits non-zero (#443).
- [vecs] Added: `update({ watch: C, onEnter: true })` also fires when `C` is added to an existing member, and `onRemove: true` fires with the removed instance when `C` is removed from an entity that stays a member, so one system can watch several optional components (#443).
