- [vecs] Changed: Query grouping is composed state rather than a runtime prototype change; direct query imports support `groupBy` without registration (#473).
- [vecs] Removed: The runtime `GroupedQuery` class. `GroupedQuery<K, R>` remains a type returned by `groupBy`; constructor calls and `instanceof` checks are no longer supported (#473).
- [vecs] Changed: Group accessors on ungrouped or destroyed queries and systems throw an error identifying the query as not grouped (#473).
