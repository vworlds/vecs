- [vecs] Changed: Each world owns its every-frame tick source, exposed as `world.alwaysTickSource`, so nested `progress` calls no longer share deltas. Add `system.hasDefaultCadence`; use it instead of comparing `system.cadence` with `ALWAYS_TICK_SOURCE`. `ALWAYS_TICK_SOURCE` is deprecated: this release `system.cadence` and `RateTickSource.source` still return it for the world's default clock and `tickSource()`/`rate()` accept it; next release it is removed and `cadence` returns `world.alwaysTickSource` (#461).
