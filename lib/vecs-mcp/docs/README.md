# MCP documentation

Connect an agent, discover world data and safely apply inspection-time changes.

Read in this order:

1. [Getting started](./getting-started.md): opt in, connect Claude Code, release worlds and manage session limits.
2. [Tools](./tools.md): targets, declared traits and pair targets, queries, entity dumps, mutations, systems and stats.
3. [Component schemas and validation](./schema.md): core reflection decorators and MCP write-policy extras.
4. [Execution semantics](./execution.md): validation, inline writes and failures.
5. [Security](./security.md): bind addresses, tokens and read-only access.
6. [Nodes and links](./topology.md): join, mount, cascade paths and reconnects.
7. [Browser clients](./clients.md): install, discover client targets, execution and replication.
8. [Watches](./watches.md): reactive event logs, session lifetime and resource subscriptions.
