# M7-11 — Docs and examples sweep

**Phase:** Closeout. Can float earlier (parallel with M7-5..M7-9) if
done by a different person.
**Depends on:** M7-1 at minimum (the `preloadPhysics` symbol must
exist). Final CHANGELOG perf-delta numbers depend on M7-10.

## Goal

Update user-facing docs and examples to teach the `preloadPhysics`
step, document the box2d3-wasm dependency and Node polyfill, and record
the migration in CHANGELOG.

## Acceptance criteria

1. `lib/vecs-physics/docs/getting-started.md` — the canonical bootstrap
   snippet includes the `await preloadPhysics()` line before
   `installPhysics`. Update prose around it.
2. `lib/vecs-physics/docs/installation.md`:
   - Document `box2d3-wasm` as a transitive runtime dependency.
   - Document the Node `navigator.hardwareConcurrency` polyfill (what
     it is, why we touch a global, and that it's guarded with `??=`).
   - Document browser `crossOriginIsolated` notes for the threaded
     "deluxe" build path; v1 ships the single-threaded `compat` build.
3. `lib/vecs-physics/docs/systems-and-phases.md`:
   - Drop references to internal TS-engine systems (e.g. `engineStep`).
     System list and ordering are unchanged from the user's
     perspective.
4. `lib/vecs-physics/docs/roadmap.md`:
   - Note that the engine is now box2d3-wasm.
   - Note that v2 deferrals (joints, raycasts, AABB/shape queries) are
     now upstream-available in box2d3-wasm but the vecs-physics-side
     adapters are still pending.
5. The four examples — `examples/hello_world.ts`,
   `examples/sensor_trigger.ts`, `examples/kinematic_platform.ts`,
   `examples/contact_events.ts` — each gain the `await preloadPhysics()`
   line before `installPhysics`. No other changes.
6. `lib/vecs-physics/CHANGELOG.md` records:
   - The migration (engine → box2d3-wasm).
   - The pinned `box2d3-wasm` version.
   - The bench speedup vs. the pre-migration baseline (numbers from
     M7-10's `npm run bench` run).
   - A note that the parity baseline is now WASM-build-determined.
7. The new `preloadPhysics` entry is reflected in any docs index or TOC
   that enumerates the public exports.
