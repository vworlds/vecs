# M7-1 — Foundation: bootstrap, adapter scaffolding, dependency wiring

**Phase:** Critical path (gates everything).
**Depends on:** none.

## Goal

Land `box2d3-wasm` as a real dependency and stand up the adapter shell
(`runtime.ts`, `state.ts`, `disposal.ts`) plus the public `preloadPhysics()`
entry point, **without** rewriting any systems. The TS engine remains in
place and authoritative for this ticket; we are only adding the new
plumbing so M7-2..M7-9 have something to plug into.

## Acceptance criteria

1. `lib/vecs-physics/package.json` lists `"box2d3-wasm": "^5.2.0"` under
   `dependencies`. `npm install` succeeds; lockfile updated.
2. `src/adapter/runtime.ts` exists and exports:
   - `preloadPhysics(): Promise<void>` — idempotent; cached `modulePromise`;
     polyfills `globalThis.navigator` and
     `navigator.hardwareConcurrency` from `node:os` `cpus().length` when
     absent (guarded with `??=`); calls `Box2DFactory()` and stores the
     module reference.
   - `getBox2D(): Box2DModule` — throws `"Box2D module not loaded. Call
\`await preloadPhysics()\` before \`installPhysics()\`."` if preload
     has not resolved.
3. `src/adapter/state.ts` exists and hosts:
   - The `PhysicsState` class shell with fields for `worldId: b2WorldId`,
     `box2d: Box2DModule`, `bodyByEntity: Map<EntityId, b2BodyId>`,
     `entityByBody: Map<b2BodyId, EntityId>`, the corresponding shape
     maps, `chainByEntity: Map<EntityId, b2ChainId>`, resolved options,
     and per-step caches (`impulseEntitiesThisStep: Set<EntityId>`,
     `pendingLinearImpulse`, `pendingAngularImpulse`). Internals may be
     stubbed; the **shape** of the class is what M7-2..M7-9 will fill in.
   - `PhysicsRoot` (Singleton component) and `PhysicsSystemTag` markers,
     moved from the surviving piece of the old `src/engine/state.ts`.
   - `registerInternalComponents(world)`, `attachPhysics(world, state)`,
     `hasPhysics(world)`, `getPhysics(world)` — same signatures as today.
4. `src/adapter/disposal.ts` exists and exports a `withAllocated<T>(make,
use)` helper that runs `.delete()` in `finally`. Document that every
   `new b2Xxx()` / factory call inside `src/adapter/` must funnel through
   it (or be matched by an explicit `.delete()` in a try/finally in the
   same function).
5. `src/install.ts` is updated so `installPhysics` constructs
   `PhysicsState` via `getBox2D()` — and therefore throws the documented
   error if a caller forgot `await preloadPhysics()`. Registration order,
   exclusivity rule, phase setup, and `attachPhysics(world, state)` flow
   are otherwise unchanged.
6. `src/index.ts` re-exports `preloadPhysics`. No other public exports
   change.
7. The old `src/engine/state.ts` is trimmed: the engine-only fields stay
   in `src/engine/` for now; only `PhysicsRoot` / `PhysicsSystemTag` /
   `registerInternalComponents` / `attachPhysics` / `hasPhysics` move to
   `src/adapter/state.ts`. Systems still importing from
   `src/engine/state.ts` for engine-only state continue to work.
8. `.agent/rules/box2d-references.md` is created with the reference-clone
   instructions verbatim from PLAN.md ("Agent guidance for fresh
   worktrees" section). A one-line pointer is appended to the `.agent/`
   list in both `CLAUDE.md` and `AGENTS.md`.
9. `.gitignore` continues to ignore `lib/vecs-physics/box2d/` and
   `lib/vecs-physics/box2d3-wasm/`. Verify the existing rule from commit
   `bd7143c` still matches.
