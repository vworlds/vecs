# M7-10 — Engine purge

**Phase:** Closeout (sequential).
**Depends on:** M7-2, M7-3, M7-4, M7-5, M7-6, M7-7, M7-8, M7-9.

## Goal

Delete every remaining TS-engine file and the engine-only utility /
math files. Re-record the parity baseline against box2d3-wasm.

After this ticket, `lib/vecs-physics/src/engine/` does not exist and no
`src/systems/` or `src/components/` file imports from it.
